# Glance Minimap

简体中文 | [English](README.en.md)

> 一个轻量级浏览器扩展，为任意网页添加透明悬浮小地图，帮助你快速理解页面结构并定位内容。

## 项目介绍

Glance Minimap 是一个基于 Chrome Extension Manifest V3 的网页小地图扩展。它会在页面右侧生成一个代码编辑器风格的全局结构预览，把标题、正文、列表、图片、代码块等内容绘制成可视化缩略图，并用视口框同步当前滚动位置。

这个扩展适合阅读长文档、API 页面、博客文章、代码展示页、单页应用（SPA）等内容密集型网页。

## 功能特性

- **全局页面预览**：在网页右侧生成固定的小地图，快速观察页面内容分布。
- **滚动位置同步**：视口框实时跟随当前滚动位置，类似编辑器 minimap。
- **拖拽快速滚动**：拖动视口框即可快速跳转到页面不同位置。
- **长按定位跳转**：在小地图上长按可按比例跳转到目标区域。
- **点击穿透转发**：普通点击小地图区域时，会尝试把点击事件转发给下层页面元素。
- **SPA 支持**：监听 History API、`popstate`、`hashchange` 和大规模 DOM 变化，适配前端路由切换。
- **滚动容器识别**：当页面主体不是 `window` 滚动时，会尝试识别主要滚动容器。
- **明暗背景适配**：根据页面背景自动调整视口框颜色，提高可见性。
- **站点级开关**：点击扩展图标可按域名隐藏或恢复小地图，并持久化保存设置。

## 安装方式

当前项目没有构建步骤，可以直接作为未打包扩展加载。

1. 打开 Chrome 或 Edge 的扩展管理页面。
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目根目录。
5. 打开任意网页，右侧会自动显示小地图。

## 使用说明

- **显示 / 隐藏**：点击浏览器工具栏中的扩展图标，可对当前站点切换显示状态。
- **拖拽滚动**：按住右侧视口框上下拖动，页面会同步滚动。
- **快速跳转**：在小地图区域长按，页面会跳转到对应位置。
- **普通点击**：短点击小地图区域时，扩展会临时隐藏自身，并尝试点击下层页面元素。

## 项目结构

```text
.
├── background.js     # 扩展后台脚本，处理工具栏点击和站点级显示状态
├── content.css       # 小地图容器、画布和视口框样式
├── content.js        # 小地图核心逻辑：绘制、滚动同步、SPA 监听
├── icons/            # 扩展图标资源
└── manifest.json     # Chrome Extension Manifest V3 配置
```

## 权限说明

项目在 `manifest.json` 中使用了以下权限：

- `storage`：保存每个站点的小地图隐藏状态。
- `activeTab`：允许扩展在当前活动标签页上响应工具栏点击。
- `<all_urls>`：通过 content script 在所有网页中注入小地图。

## 开发说明

修改源码后，在扩展管理页面点击「重新加载」即可生效。项目当前不依赖打包工具、包管理器或后端服务。

主要开发入口：

- `content.js`：调整小地图绘制逻辑、交互行为、SPA 适配和滚动容器检测。
- `content.css`：调整小地图尺寸、透明度、视口框样式和层级。
- `background.js`：调整工具栏按钮行为和站点级状态管理。

## 兼容性

该扩展使用 Manifest V3，主要面向 Chromium 内核浏览器，例如 Chrome、Edge、Brave 等。
